# Scam Link Checker

A lightweight Python tool for analyzing suspicious links and domains.

## Features

- URL and domain analysis
- Server IP detection
- Server and hosting information
- IP geolocation
- ASN and organization information
- HTTPS and SSL certificate checks
- Domain registration age
- Redirect chain detection
- VirusTotal threat intelligence
- Automated risk score

## VirusTotal API

Set your API key as an environment variable:

    export VT_API_KEY="YOUR_VIRUSTOTAL_API_KEY"

Never put your real API key directly in the source code.

## Disclaimer

This tool provides automated technical indicators only.
A low-risk result does not guarantee that a website is safe.

Do not enter passwords, OTPs, payment information, or other sensitive data into suspicious websites.
